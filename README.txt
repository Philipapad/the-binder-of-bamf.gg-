BAMF Offline Binder v2
This is a separate unofficial Pokémon official-artwork gallery, not BAMF.gg itself. It uses artwork URLs from the public PokeAPI sprites repository. Images cache as loaded; the Save all button attempts to cache all 1,025 images and may use substantial data/storage.

To update GitHub Pages:
1. In your repository choose Add file > Upload files.
2. Upload and replace index.html, manifest.webmanifest, sw.js, and icon.svg.
3. Commit changes and wait for Pages to publish.
4. Open the published URL in Chrome while online and reload.
5. Press Save all 1,025 images offline and wait for completion.
6. Turn off Wi-Fi and test again.

This does not reproduce BAMF.gg's own binder interface, account, saved progress, or proprietary card data. It is an artwork gallery. Unofficial; not affiliated with BAMF.gg, Nintendo, or The Pokémon Company.
